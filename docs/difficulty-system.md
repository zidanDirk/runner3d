# 难度与关卡公平性

`src/game/difficulty.ts`是版本1难度输入，`progression/balance.ts`汇总它与既有道具/经济/任务配置。RULES只引用速度/路段值，不另保留一份可漂移的数字。未知字段、非有限数、超范围、过密间距、不支持的版本或无序阶段均拒绝。

当前保留Task11实测默认值：速度`min(24,16+distance×0.004)`m/s，26m一行，首行48m；普通行两条受阻跑道，低栏/高架/箱墙权重各1，每第五行无障碍。每行4枚路线金币，起步6枚；180m后每行18%道具。不是秘密DDA，不读取玩家历史表现调整难度。

阶段标签为0/250/600/1200/2000m的适应/基础/进阶/挑战/高速；只解释连续速度曲线，不在边界突然加障碍。每米障碍密度约1.6/26不变，随速度增加的每秒压力约0.985→1.477个障碍实例；2km后封顶，五行一次缓和继续存在。内部Difficulty Score=`100×speed/16`，仅为相对时间压力指标，不是心理量表。

## 共享规则和证书

`motion.ts`从原引擎逐句提取固定步运动，GameEngine和可达性验证共同调用；`collision.ts`仍是同一AABB，实际X/Y、换道插值、跳跃速度/重力、滑铲剩余时间和动作互斥不变。没有第二套“近似物理”或缩小碰撞体。

`LevelGenerator`生成候选后，在提交前调用`validateRowTransition`。把局部场景整体平移到速度已饱和处，在24m/s下，从上一障碍最大碰撞区清除之后的三个落地跑道中心出发，等待0.35s反应+0.08s输入延迟，再用真实步长1/120s验证至下一行完全通过。两次换道分别等实际0.18s完成，碰撞每tick检查；正向路径精确回放，结束时落地、横向归位，因而可在连续行之间组合。

优先使用直接安全跑道见证，异常布局使用12宽beam搜索：每6tick决策一次，最多4096节点；状态含lane/x/fromX/laneElapsed/y/velocityY/slideRemaining与时间距离。只为去重键离散化（位置0.1m、速度0.5m/s、计时按决策tick），保留的状态数值不舍入。正结果必须实际回放；阴性或预算耗尽只表示本搜索没找到路线，不证明所有连续输入都不可行。默认生成失败最多1次尝试后报错，禁止无上限重试或静默清除障碍冒充成功。

相同相对布局可平移复用证书，最多64个模板，不缓存seed历史；key包含间距、safeLane及障碍kind/lane/相对距离/collected状态。初始行与普通行独立处理。默认3000种子×10km实测覆盖57个模板；该优化只发生在生成时，不每帧运行搜索。它保证有一条不依赖道具的路径，不保证任意晚操作或空中错误姿态都能获救。

## 反应与可见性

`game/reaction.ts`从实际运动核测量跳跃达到低栏高度的起效时间，换道/滑铲用原参数。窗口扣除碰撞前沿、动作起效、输入延迟与准备时间。slow/ordinary/fast是假设，分别不是经过真人标定的用户群。

浏览器用真实相机矩阵、Canvas CSS大小、实际Fog近远值和AABB投影，以0.25m扫描，比较12/18/24 CSS px识别代理和35%未雾化阈值。遮挡、GLB条纹实际大小、注意力和色觉没有建模，投影结果不能等同首次被人看清。手机低栏在更严格识别假设下出现负窗口，详见最终报告。

对应调整是小屏≤1100px、速度≥20m/s时的只读路况预警：实际障碍、4..50m、最多两行、24CSSpx符号，不读取safeLane答案或自动输入。准备/暂停/结束隐藏，宽屏隐藏，Reduced Motion无需摆动动画。20m/s约1km后才启用，权衡是保留早期简洁HUD；不能宣称覆盖所有较慢反应或早期识别问题。

50m是设计预警范围，约49m截图是冻结取样，不证明首次真实像素出现时刻。原HUD约20Hz的.05s是发布阈值而非最大延迟；额外以0.20s发布/呈现延迟作敏感性假设（不是实测上限），24m/s时剩45.2m。低栏慢档余量约0.890s，但图标理解、主机卡顿、遮挡及真机仍需人工验证。

开发`/?debugBalance=1`每250ms只读显示阶段、速度、密度、道具概率、seed、最新生成证书、行距反应预算、钱包与升级。沿用`?testMode=1&distance=2200`定位；预览局不写成长。生产移除面板与capture入口，URL不能改钱包/等级。

# Runner3D Task12 平衡决策

目标是让现有三跑道循环可解释、可复现并能继续调参，保留原品牌、动作手感、城市和15个模型。玩家仍靠躲避/收集获得分数及成长，失败正常结算后可立即重试；本轮不加付费、等待、内容或秘密DDA。

首先保存了Task11实际源码、71张基线和模型哈希，读取实际配置后执行原始实验。核心参数与旧文档总体一致：固定120Hz，跑道宽2.8m，换道.18s，跳跃初速10.5/重力22，滑铲.75s，速度16→24、每米+.004；4枚路线金币、每币25分，钱包只真实死亡单次结算。历史程序化城市文档仍有旧工厂版本叙述，当前Manifest/工厂实际为2.1.0，不据历史文字改资产。

本轮把已有连续曲线、密度、权重、金币及道具频率集中到版本化DifficultyConfig，并增加真实运动核证书和分析工具。速度、碰撞、动作、障碍序列、金币、三种道具参数、价格100/250/500、九任务及存档schema1均保持。3000条主实验逐局原/新结果完全相同，是兼容性证据；它不证明原配置已达到最优。

三策略在同一实验上限下观测平均生存313.739/995.291/2726.393m，平均金币37.576/130.596/404.020；expert有294/1000局删失。主实验6000局加3600道具/升级对照、3600生涯局，共13200局主要实验。新手首次升级约4.33局，全部九升级约47局；普通约16..17局，高手约8..10局（删失及小样本限制见报告）。这些不是人的平均值。

重要未解决问题：磁铁边际金币回收局数可达数百至千余局，部分护盾时长升级在60seed单元中无观测增益；不能宣称每级都已证明值得购买。100局后生涯样本钱包有明显积累，现有内容有限。贸然统一降价、增加金币消耗或拉长等待缺少真人依据，因此不在本轮强行调整；后续应把升级效用、识别/失误与更长路线纳入真实试玩后再定向试验。

反应灵敏度发现手机低栏依赖识别代理假设：12px可为正，18/24px时可能不足。这与物理路线有证书是两件事。本轮据此添加高速度小屏路况提示作为可见预警措施，保持世界、速度和碰撞不变；预警的真人识别收益仍需实机试玩，机器人不读取HUD。

## 真人试听

手机扬声器、普通耳机分别测试 8 项：金币、跳跃、落地、滑铲、换道、碰撞、结束、速度里程碑。每项填试听设备、实际听到、响度/刺耳/突兀/辨认度、问题编号。另听连续金币、多音效重叠、静音是否彻底、暂停与恢复。自动 Web Audio 节点和离线 PCM 校验单列，不能替代听感。

## 受邀玩家

组织者可使用 p01～p10 匿名编号；同一人全部问题复用同一 ID，不记录姓名、账号、联系方式或精确位置。本项目没有代发邀请，也没有远程反馈后台。推荐5～10名实际玩家，覆盖桌面/iPhone/Android，按实际可用人数报告，不凑数。

先让玩家独立完成：打开候选 → 找开始 → 自选引导 → 换道/跳/滑 → 金币/道具 → 自然失败 → 结算 → 商店 → 任务 → 自主再次开始 → 设置/反馈。观察者避免先讲答案，额外指导要注明发生步骤。

## 反馈归档与风险

复用游戏“Beta反馈”生成/复制/下载，页面明确尚未发送，由组织者接收并人工去隐私、分类、审核。结构化导入见 [beta-feedback-import.md](beta-feedback-import.md)。未审核内容不得交给执行器，不自动发布。

P0：不能开始、大量资源失败、存档损坏、安全/计分钱包漏洞，阻止发布。P1：真实手机不可操作、常见设备持续卡顿、关键页不可用、普遍不理解操作，解决后再扩大。P2：局部UI/动画/音效/一般平衡；P3：非关键细节和扩展。按真实影响分级，不能为发布日期降低严重程度。
